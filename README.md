# Ecommerce Website

A full-featured ecommerce website built with HTML, CSS, and JavaScript. Features product browsing, shopping cart, and a checkout flow with credit card visualization.

## Features

- **Product Catalog** — Browse products with images and descriptions
- **Shopping Cart** — Add items, update quantities, and view cart contents
- **Checkout Flow** — Complete purchase with credit card input and validation
- **Responsive Design** — Optimized for desktop and mobile devices
- **Interactive UI** — Smooth animations and transitions

## Tech Stack

- **HTML5** — Semantic markup and structure
- **CSS3** — Styling with Flexbox, Grid, and animations
- **JavaScript (jQuery)** — Dynamic interactions and DOM manipulation
- **IMask** — Input masking for credit card fields

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional, for development)

### Installation

```bash
git clone https://github.com/RajgopalPandilwar/Ecommerce-Website.git
cd Ecommerce-Website
```

### Usage

Simply open `index.html` in your browser, or use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

Then navigate to `http://localhost:8000` in your browser.
